# Contributors

DLSS5ForUE5 is an independent community project. Contributions are credited according to the changes actually incorporated into the repository.

## Code contributions

- **[@scragnog](https://github.com/scragnog)**: Authored [PR #2](https://github.com/praveenkumarappu/DLSS5ForUE5/pull/2), merged into the project in September 2026. The work corrected NGX feature lifetime and GPU-fence retirement, separated per-view and per-pass temporal histories, improved scene-guide handling and shutdown safety, and added regression coverage.

## Contributions under review

- **[@scragnog](https://github.com/scragnog)**: Authored [PR #5](https://github.com/praveenkumarappu/DLSS5ForUE5/pull/5), which remains open. The v0.6.1 validation source uses or adapts part of the approach to pixel-space motion-vector scaling, depth/motion guide alignment, highlight preservation and launch-CVar synchronization. PR #5 has **not** been merged in full. Its custom-stencil control-mask shader, distortion-field input, scaling-ratio mode controls and expanded experimental style controls are **not claimed as implemented or validated** in v0.6.1.

Acknowledgement of an open PR does not mean its code has been merged. Review and tests are required before including additional changes.
